# 2026-04-10_lecon01_fondamentaux

Document source : [[2026-04-10_lecon01_fondamentaux.docx]]

## Résumé

Première leçon du corpus, en avril 2026 — antérieure de deux mois à tous les autres parcours.

Elle présente Claude Code comme **un agent de codage autonome dans le terminal**, distinct d'un assistant conversationnel : il lit les fichiers, explore le dépôt, exécute des commandes et des tests, modifie le code, crée des branches et des commits.

La **boucle agentique** y est schématisée — prompt, analyse du contexte, proposition d'action, approbation, exécution, observation, itération — ce qui reste la meilleure description de ce qui se passe réellement pendant une session.

Le point signalé comme contrainte principale est la **fenêtre de contexte** : elle se remplit vite et conditionne tout le reste. Deux ans d'usage plus tard, c'est resté le facteur limitant le plus concret.

Format : 45 à 60 minutes, sept activités, dont le mode non interactif `-p` — celui-là même sur lequel repose aujourd'hui toute l'automatisation des jobs.
