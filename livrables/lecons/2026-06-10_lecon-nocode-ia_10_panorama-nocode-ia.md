# 2026-06-10_lecon-nocode-ia_10_panorama-nocode-ia

Document source : [[2026-06-10_lecon-nocode-ia_10_panorama-nocode-ia.docx]]

## Résumé

**Refondation du parcours.** La leçon le dit explicitement : les neuf premières leçons ont suivi l'actualité, on reprend ici des fondations propres et progressives. C'est de cette leçon que date le contenu pédagogique durable.

Le vocabulaire de base est posé : le **no-code** consiste à assembler des briques visuelles — déclencheurs, actions, conditions — plutôt qu'à écrire du code ; le low-code en est la variante avec un peu de code optionnel.

Côté IA : un **LLM** génère du texte à partir d'un prompt, découpe le texte en **tokens** et travaille dans une **fenêtre de contexte** limitée. Cas d'usage principaux : résumer, classer, extraire, rédiger, traduire, répondre.

Le paysage des trois plateformes majeures — Zapier, Make, n8n — est comparé.
