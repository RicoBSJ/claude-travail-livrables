Document source : [[2026-07-01_lecon-enneagramme_05_type-3-battant-performeur.docx]]

## Résumé

Type 3 — le Battant, ou Performeur. Désir : se sentir valorisé, digne d'être aimé. Peur : être sans valeur, n'être rien en dehors de ses accomplissements. Passion : **la vanité**, entendue comme confusion entre l'être et le paraître.

La comparaison avec le Type 1 est ce qui éclaire le mieux : **les deux sont exigeants, mais le juge diffère**. Le 1 se mesure à ses propres standards internes, le 3 à l'image qu'il projette. D'où la question centrale du type — distinguer la persona sociale de l'identité authentique.

Vertu : l'authenticité. Dynamiques : vers le **9** sous stress (effacement, arrêt), vers le **6** en sécurité (loyauté, coopération).

C'est le type dont la culture professionnelle contemporaine fait le plus l'éloge, ce qui rend son travail d'auto-observation particulièrement difficile.
